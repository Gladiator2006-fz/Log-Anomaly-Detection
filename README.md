# AI-Powered Log Anomaly Detection System for Enterprise IT Infrastructure

## 📌 Overview
This project aims to develop an AI-powered system that detects anomalies from enterprise IT logs in real time. The system leverages machine learning techniques to identify abnormal patterns, reduce false positives, and assist IT teams in proactive incident management.

---

## 🎯 Objectives

- Detect anomalous events from enterprise logs.
- Reduce manual log monitoring efforts.
- Improve incident response time.
- Build an interactive dashboard for visualization.
