Model Evaluation

Held-out test-block metrics from a live retrain. Retraining runs on the server and may take several seconds.

Isolation Forest, in plain language

The model isolates unusual log lines by randomly partitioning features. Lines that isolate quickly receive a higher score. Labels are not used to compute the score; they are used only to train on normal blocks, choose a validation threshold, and report held-out metrics.
1Raw logsHDFS-2k structured lines
2FeaturesEvent, component, train-only frequencies
3Block splitLeakage-safe 60 / 20 / 20
4Isolation Forest200 trees, contamination auto
5ThresholdChosen on validation only
6Test evaluation399 held-out test blocks

Why recall stays low on HDFS-2k

This sample is almost one line per block, so the model has little sequence context. On the committed 399-block test split the official result is 1 true positive out of 13 actual test anomalies. That is a dataset limitation. The 0.35% corpus detection rate is a different statistic.
